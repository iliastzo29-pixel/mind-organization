# 🪽 Hermes (local agent)

Runs on the founder's own Mac. Takes over recurring work so the chat assistant does not have to:

- **Price guardian:** checks competitor prices and writes them into a data table.
- **Deployment:** builds and publishes the website after approved changes.
- **Source guardian:** checks once a month whether a law page has changed ("as of …").

Hermes reports what it did. It does not decide.
